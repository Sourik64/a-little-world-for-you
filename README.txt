HOW TO UPDATE YOUR EXISTING GITHUB WEBSITE:
1. Download and unzip this package on your computer.
2. Open your GitHub repository: Sourik64/a-little-world-for-you
3. Replace the existing index.html with this new index.html.
4. Upload the entire images folder (containing all four JPG files) to the repository root.
   Keep the folder name exactly: images
5. Commit the changes.
6. Wait a few minutes, then refresh:
   https://sourik64.github.io/a-little-world-for-you/
